# 🧮 Smart Calculator Pro

A modern, responsive, and feature-rich calculator built using **HTML, CSS, and JavaScript**.
Smart Calculator Pro provides a clean user interface with **basic arithmetic, scientific calculations, calculation history, theme switching, copy results, export history, animations, and sound effects**.

---

## ✨ Features

### 🔢 Basic Calculator

* Addition `+`
* Subtraction `−`
* Multiplication `×`
* Division `÷`
* Percentage `%`
* Decimal calculations
* All Clear `AC`
* Delete `DEL`
* Toggle sign `±`
* Responsive calculator keypad

### 🧪 Scientific Calculator

Includes additional mathematical operations such as:

* Square root `√`
* Powers `xʸ`
* Parentheses `( )`
* Pi `π`
* Euler's number `e`
* `sin()`
* `cos()`
* `tan()`
* `log()`
* Natural logarithm `ln()`

### 📜 Calculation History

* Automatically stores previous calculations
* View calculation history from the History panel
* Clear complete history
* Export calculation history
* Memory support with `MC`, `MR`, `M+`, `M-`

### 🎨 Modern UI

* Responsive design
* Dark/Light theme support
* Animated background blobs
* Glassmorphism-inspired interface
* Smooth button animations
* Ripple click effects
* Font Awesome icons
* Google Poppins font

### 📋 Utility Features

* Copy calculation results
* Keyboard-friendly calculator experience
* Click sound effects
* History export functionality

## 🎯 How to Use

### Basic Calculation

1. Enter numbers using the calculator keypad.
2. Select an arithmetic operator.
3. Enter the next number.
4. Press `=` to calculate the result.

Example:

```text
25 + 75 = 100
```

### Scientific Mode

Click the **Scientific** button to open additional mathematical functions.

Example:

```text
√25 = 5
```

```text
2 × 2 = 4
```

## 🌙 Theme

Use the theme button in the calculator header to switch between available visual themes.

The interface is designed to provide a comfortable experience in different lighting conditions.

## 📜 History

Every completed calculation can be displayed in the **History** panel.

The history section allows you to:

* View previous calculations
* Clear saved history
* Export calculation history

---

## 📋 Copy Result

The **Copy** button allows users to quickly copy the current calculator result to the clipboard.

This makes it easier to use the calculated value in another application.
